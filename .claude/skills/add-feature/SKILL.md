# 機能を足す

作る前に、何を作るかを河津さんと合わせてから進める。

## 1. 決める

- 何を入力し、どこに保存し、どう見せるかを3行で書いて河津さんに見せる
- テーブルが変わるなら、どの列を足すかもここで書く
- 範囲が広いときは、先に使える最小の形を提案する

## 2. 下から順に作る

1. テーブル: 変えるなら `db-migration` スキルの手順で行う
2. API: `src/worker/` に追加する。入力は検査し、エラーは理由つきで返す
3. 画面: `src/client/` に追加する。スマホで片手で入力できる大きさにする
4. 日付は日本時間で区切る。世界標準時の日付を直接使わない

## 3. テストを書く

- API は `app.request()` で呼ぶテストを `src/worker/*.test.ts` に書く
- 日付の境目（日本時間の0時前後）に関わる処理は境目のテストを入れる
- 画像解析のように外の API を使う部分は、決まった値を返す偽物に差し替えて試す

## 4. 確かめる

- `pnpm verify` を通す
- 画面を変えたら `ui-check` スキルで見た目を確かめる
- 終わったら `ship` スキルへ進む
