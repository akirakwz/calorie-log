# 画面を確かめる

## 手順

1. `e2e/` に、確かめたい操作のテストを足す（入力して保存し、表示が変わるところまで）
2. 確かめたい画面で `page.screenshot({ path: "test-results/<名前>.png", fullPage: true })` を撮る
3. `pnpm test:e2e` を回す（開発サーバーは自動で立ち上がる）
4. `test-results/` のスクショを読み、次を見る
   - 横にはみ出していないか
   - 文字や入力欄が小さすぎないか
   - エラーの表示が出ていないか
5. 河津さんに見せるときは、スクショをファイルで送る

## 注意

- ブラウザはクラウド環境に入っているものを使う。`@playwright/test` は 1.63.0 ちょうどに固定してあるので上げない（上げるとブラウザが見つからなくなる）
- 手元では Cloudflare Access が無い。認証を入れたら、手元だけで外す仕組みを用意する
